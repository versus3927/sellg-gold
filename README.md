# Бот «Донат и заработок» с админ-панелью

Telegram-бот на aiogram 3: каталог доната по играм, оплата переводом по реквизитам с проверкой чека админом, баланс, рефералка, задания и полная админ-панель прямо в боте.

## Что умеет

**Покупатель**
- 🛒 **Донат** — категории (игры) → товары → оплата. Перед оплатой бот может спросить ID в игре или ник (настраивается у каждого товара).
- 💳 **Оплата по реквизитам** — номер карты, получатель, кнопка «📋 Скопировать реквизиты». Дальше «✅ Я оплатил» → покупатель присылает скриншот или PDF чека → заказ уходит админу на проверку.
- 💰 **Оплата с баланса**, пополнение баланса через те же реквизиты с чеком.
- 💰 **Заработок** — реферальная ссылка (% с оплат друзей и/или бонус за каждого), ежедневный бонус, задания «подпишись на канал».
- 👤 **Профиль** — баланс, пополнение, вывод средств, промокоды. 📦 **Мои заказы** — статусы всех заказов.

**Админ** (кнопка «⚙️ Админ-панель» или команда /admin)
- 🧾 Чек приходит админу фото/файлом с кнопками **✅ Подтвердить** / **❌ Отклонить** (с причиной). После подтверждения — кнопка **📦 Заказ выполнен**. Покупатель получает уведомление на каждом шаге.
- 📊 Статистика: пользователи, оплаты за день/неделю/месяц, балансы, выплаты.
- 📦 Каталог: категории и товары (цена, описание, фото, вопрос покупателю, скрыть/показать, порядок).
- 💳 Реквизиты: способы оплаты (номер, получатель, примечание), можно выключать и добавлять новые.
- 👥 Пользователи: поиск по ID/@username, начисление/списание баланса, бан, личное сообщение, история операций.
- 📢 Рассылка любого сообщения всем пользователям.
- 🎁 Промокоды, 📋 задания, 💸 заявки на вывод.
- ⚙️ Настройки без правки кода: приветствие (с картинкой), тексты, контакт поддержки, реф. процент, бонусы, минимальные суммы, обязательная подписка на канал.

При первом запуске автоматически создаётся способ оплаты **«💳 Перевод на карту»**: `2204 3206 1762 2990`, получатель **Максим Ш.** Поменять его можно в «⚙️ Админ-панель → 💳 Реквизиты».

## Деплой на Railway

1. **Токен бота.** В [@BotFather](https://t.me/BotFather) создайте бота (`/newbot`) и скопируйте токен.
2. **ID админов.** Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot). Если админов несколько, укажите их ID через запятую.
3. **Код на GitHub.** Загрузите содержимое этой папки в **приватный** репозиторий (файл `.env` не загружайте).
4. **Проект на Railway.** [railway.com](https://railway.com) → **New Project** → **Deploy from GitHub repo** → выберите репозиторий. Railway сам соберёт бота по `Dockerfile`.
5. **База данных.** В проекте нажмите **+ Create** → **Database** → **PostgreSQL**.
6. **Переменные.** Откройте сервис бота → вкладка **Variables** и добавьте:

   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от BotFather |
   | `ADMIN_IDS` | ваш ID, например `123456789` или `123,456` |
   | `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` (это ссылка на базу из шага 5) |

7. Railway перезапустит бота. В **Deployments → View logs** появится строка `Бот @имя_бота запущен`.
8. Каждый админ должен **написать боту /start**, иначе бот не сможет присылать ему чеки.

**Вариант без GitHub (Railway CLI).** Из папки проекта выполните `npm i -g @railway/cli`, затем `railway login`, `railway init` и `railway up`. Код загрузится напрямую. Базу и переменные добавьте так же, как в шагах 5–6.

> Без PostgreSQL бот работает на SQLite, но тогда нужен Volume (сервис → **Settings → Volumes → Add Volume**, путь `/data`), иначе база обнулится при следующем деплое. Бот сам находит подключённый Volume.

**Необязательные переменные:**
- `ADMIN_CHAT_ID` — ID группы (вида `-100…`), куда будут приходить чеки вместо личных сообщений. Добавьте бота в группу. Нажимать кнопки в группе могут только админы из `ADMIN_IDS`.
- `TIMEZONE` — часовой пояс дат (по умолчанию `Europe/Moscow`).

**Важно:** держите запущенной только одну копию бота. Если бот одновременно работает на Railway и у вас на компьютере, Telegram отдаёт сообщения только одному из них, а в логах появляется ошибка `Conflict`.

## Первая настройка после запуска

1. `/admin` → **📦 Каталог** → «➕ Добавить категорию» (например, `🔫 Standoff 2`) → «➕ Добавить товар» (например, `100 голды`, цена, вопрос `Введите ваш ID в игре`).
2. **💳 Реквизиты** — проверьте карту и получателя, при необходимости добавьте СБП или другой банк.
3. **⚙️ Настройки** — приветствие, контакт поддержки (юзернейм админа), ссылка на канал, реф. процент, бонусы.
4. Если нужна обязательная подписка на канал, добавьте бота в админы канала и укажите `@канал` в «🔒 Обязательная подписка».

## Локальный запуск (для проверки)

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env
```

Заполните `BOT_TOKEN` и `ADMIN_IDS` в `.env`, затем:

```bash
python -m bot
```

## Структура

```
bot/
  __main__.py      запуск, создание таблиц, реквизиты по умолчанию
  config.py        переменные окружения
  db.py            модели БД (SQLAlchemy) и атомарное изменение баланса
  settings.py      настройки, которые меняются из админки
  handlers/        пользовательские разделы
  handlers/admin/  админ-панель
```
